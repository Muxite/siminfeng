Save the immutable Docker-reported ID before hashing/linkage. Derive the
linux/amd64 config digest from saved bytes, following OCI indexes/manifests
and verifying referenced JSON SHA256 values, or hashing a classic Docker
archive config. Reject missing/ambiguous configs and metadata mismatches.
All docker run probes use the derived config ID, never an index or repo@digest.

Record identity fields:
- Id and docker_reported_id: unchanged observation from docker image inspect.
- config_digest: archive-derived linux/amd64 config SHA256; runtime probe ID.
- manifest_digest: selected OCI platform image manifest digest, else null.
- index_digest: original OCI index from archive/typed Buildx metadata, else null.
- index_manifests: archive catalog descriptors.
- docker_id_in_archive_index: whether inspect ID appears in catalog descriptors.
- id_note: explanation of distinct objects.
- archive.sha256/bytes: independent identity of delivered tar bytes.
