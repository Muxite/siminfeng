# Assignment T-FAC (campaign c2-resume, x86-main; owner Claude Opus; worker Codex) — the MoE inference-engine factory pipeline (glue over existing CCs)
User goal: "a software factory that takes an MoE model, inspects the stats, inspects the system, and builds an inference engine that runs the model in much less memory; accuracy roughly the same; load time/TTFT/tok-s may change; KV-cache techniques allowed."
Existing components (READ their READMEs; reuse, do not reimplement): cc/model_inspect (model-stats/0), cc/resource_observe (resource-sample/0) + cc/engine_handoff/hosts/*.json (host profiles), cc/moe_planner (plans + emitted lab tests; PLANNER.md rules), cc/build_engine (Build CC v2: --patch, --cmake-define, --extra-target, --linkage), component patches cc/q8_reuse (accepted D029), cc/kv_quant_fix (T-KVB2, pending GPU verification), cc/pap (placement-aware precision recipe; pending), bin/lab (submit/run with input identity + embedded test defs), cc/engine_handoff/envelopes.py (proposal/admit/result), cc/nsys_decode (profile breakdown).
Deliver cc/factory/factory.py with stages, each writing a JSON artifact into a run directory (artifacts/factory/<run-id>/): `inspect` (model_inspect) -> `system` (resource_observe once + host profile) -> `plan` (moe_planner with budget args) -> `recipe` (for each selected plan: model transform steps (e.g. llama-quantize --tensor-type recipe from cc/pap, with input/output hashes to be filled), engine build args (base commit + ordered patch list from a components registry file cc/factory/components.json with status per component: accepted/pending/rejected and evidence decision IDs; only accepted components by default, `--include-pending` opt-in), runtime argv) -> `build` (calls build_engine.py; supports --dry-run) -> `measure` (submits lab job from the plan's emitted tests; --dry-run prints commands) -> `report` (joins predictions vs measured results from lab result.json: memory, decode, prefill/TTFT, KLD; flags prediction error; classifies each result with the campaign claim categories). Every stage records inputs/outputs sha256 and is resumable (skip if output exists and inputs unchanged). CLI: `factory.py run --model M.gguf --host x86-main --budget-gpu-mib N --ctx C [--max-kld X] [--stages a,b,..] [--dry-run]`.
components.json initial content from decisions: q8_reuse accepted (D029), kv_quant_fix pending (D028/T-KVB2), hybrid_split rejected-small-expert-regime (D030/D031), moe_static_hot rejected (D024), gpu_budget infrastructure (D021/D023: cooperative cap for budget experiments), flash-attn runtime flag recommended for long ctx (D028).
