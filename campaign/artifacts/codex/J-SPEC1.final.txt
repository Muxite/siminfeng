## Capture

```bash
/app/llama-routing-trace -m /models/model.gguf \
  -p 'Explain how a cache works.' -n 64 -ngl 0 -c 2048 \
  --trace-out /out/routing.jsonl > /out/generated.txt 2> /out/capture.log
python3 cc/routing_trace/validate_generic_trace.py /out/routing.jsonl
python3 cc/expert_replay/expert_replay.py --help
```

Use a separate output path per run: `--trace-out` truncates an existing file.
Only one text sequence is supported (`seq=0`). Prompt-file handling (`-f`) and
BOS tokenization come from common; no chat template is added. `-n` defaults to
32 and must be finite/nonnegative. Generation uses raw-logit argmax, ignores
sampling settings, and evaluates exactly N generated tokens, including EOG;
`-n 0` captures only prefill. `tok` is the absolute evaluated input position,
including BOS, and starts at zero. Phases describe submitted tokens, so a
single-token prompt chunk remains prefill. Context overflow is refused.

The first line is metadata, emitted after the first submission has validated:

```json
{"type":"metadata","arch":"example","n_layer":2,"layers":2,"model_path":"/models/model.gguf","model_sha256":null,"experts":16,"n_expert":[16,0],"k":[2,0],"shared_experts_routed":false,"shared_experts_present":[true,false]}
```

`n_expert` and `k` are arrays indexed by **model layer ID**, with zero for dense
layers. `experts` is the maximum per-layer expert count, and `layers` aliases
`n_layer` for `cc/expert_replay`. A full-file SHA is omitted (`null`) to avoid
reading a multi-gigabyte model just for capture identity; record an existing
manifest hash alongside the run when available. Model path and architecture
strings are JSON escaped. Each routing row is:

```json
{"tok":0,"layer":0,"experts":[3,12],"weights":[0.4,0.6],"phase":"prefill","seq":0}
```

The last line is emitted only after successful generation and capture:

```json
{"type":"metadata","trace_complete":true,"tokens":1,"records":1}
```

The footer's `type` lets the existing expert_replay parser skip it as metadata
without counting it as malformed input. `tokens` counts evaluated input
positions, not just generated tokens; `records` counts routing rows. Missing
footer, partial JSON, wrong counts, missing tokens/layers, or data after the
footer are rejected by `validate_generic_trace.py`. Always validate before
replay: expert_replay itself does not enforce this completion protocol. Its
coverage diagnostic assumes every model layer routes; mixed dense/MoE models
therefore report incomplete layer coverage even when capture is complete.
Its global expert bound also cannot enforce individual per-layer bounds; the
validator does. Use `cc/expert_replay`, not the legacy `trace_replay.py`, for
generic traces. The latter retains Granite-only 32-expert/top-8 assumptions and
accepts only legacy `pos` records without metadata/footer.

## Callback contract and limits

The tool derives `n_expert` from `ffn_moe_probs-N` shape `{E,T,1,1}` and `k`
from `ffn_moe_topk-N` shape `{K,T,1,1}`, never from hardcoded model dimensions
or tensor strides. It copies I32 IDs using `nb[]` (top-k may be a strided view).
F32 weights must be `{1,K,T,1}` or `{K,T,1,1}`. It observes exact stages
`ffn_moe_weights-N`, `_softmax-N`, `_norm-N`, `_scaled-N`, retaining the last
stage. Sum/clamp helpers are excluded. Weights must be finite/nonnegative;
IDs must be distinct and within that layer's router dimension.

Shared expert presence is discovered through `ffn_shexp-N`,
`ffn_shexp_out-N`, `ffn_moe_shexp-N`, or `ffn_shared_out-N` callbacks. These
branches are always computed when present (possibly sigmoid gated), are not
top-k selections, and never appear in routed expert arrays. Architectures
without these shared-branch callback names require a hook extension before
interpreting a false presence flag. Custom graph naming, remapped expert IDs
(e.g. grouped GroveMoE), and architectures bypassing `build_moe_ffn` need
separate validation; “generic” means shape independent within this callback
contract, not a guarantee for every architecture.

Qwen35moe requires routing in every main layer even on the first submission.
For other architectures, first-submission discovery permits dense layers; later submissions must have
identical routed-layer coverage, dimensions and shared presence. Missing,
duplicate or reordered tensors fail capture. A model whose first graph omits
an entire routed layer cannot be distinguished from a dense layer by callback
observation alone. Unexpected physical batch splitting is rejected.

Submissions contain at most `min(n_batch,n_ubatch)` tokens and are synchronized
before emission. Owned data is bounded by one submission's layer/top-k values
plus one observed tensor's device readback, rather than total generated tokens.
Output is ordered by token then model layer, and flushed after **each token**.
Host buffers are read after callback synchronization; device buffers use
`ggml_backend_tensor_get`. No routing tensors are mutated.

Tracing has material overhead: selected callbacks force scheduler range
synchronizations and device readbacks. Logits are requested for every prompt
token to prevent final-layer pruning. Warmup and backend sampling are disabled.
This can inhibit fusion and add output/LM-head work. Captures are routing
evidence, not performance-neutral timing runs; numerical equivalence has not
been established. Any failed decode, callback validation, output write or
close returns nonzero; reject the trace even if a footer is visible after an
I/O failure. Flush is not fsync or an atomic completion transaction.

#!/usr/bin/env python3
"""Generic logical expert-cache replay; Python 3.10 standard library only."""
import argparse
import csv
import hashlib
import json
import math
import sys
from collections import Counter, defaultdict, deque
from pathlib import Path


def integer(x, minimum=0):
    if type(x) is not int or x < minimum:
        raise ValueError(f'expected integer >= {minimum}, got {x!r}')
    return x


def read_trace(path, layers=None, experts=None):
    rows, metadata, errors, seen = [], {}, [], set()
    truncated = 0
    with Path(path).open(encoding='utf-8') as source:
        for number, line in enumerate(source, 1):
            try:
                obj = json.loads(line)
                if not isinstance(obj, dict):
                    raise ValueError('expected JSON object')
                if obj.get('type') == 'metadata':
                    for name in ('layers', 'experts'):
                        if name in obj:
                            value = integer(obj[name], 1)
                            if name in metadata and metadata[name] != value:
                                raise ValueError('conflicting metadata')
                            metadata[name] = value
                    continue
                seq = integer(obj.get('seq', obj.get('request', 0)))
                tok = integer(obj.get('pos', obj.get('tok')))
                layer = integer(obj.get('layer'))
                ids = obj.get('experts')
                if not isinstance(ids, list) or not ids:
                    raise ValueError('experts must be a nonempty list')
                ids = [integer(e) for e in ids]
                if len(set(ids)) != len(ids):
                    raise ValueError('duplicate expert IDs')
                if obj.get('phase') not in ('prefill', 'decode'):
                    raise ValueError('phase must be prefill or decode')
                if 'weights' in obj:
                    ws = obj['weights']
                    if (not isinstance(ws, list) or len(ws) != len(ids) or
                        any(type(w) not in (int, float) or not math.isfinite(w) or w < 0 for w in ws)):
                        raise ValueError('invalid aligned weights')
                key = (seq, tok, layer)
                if key in seen:
                    raise ValueError('duplicate sequence/token/layer')
                seen.add(key)
                rows.append(dict(seq=seq, tok=tok, layer=layer, experts=ids, phase=obj['phase']))
            except (ValueError, TypeError) as exc:
                tail = not line.endswith('\n')
                truncated += int(tail)
                errors.append(dict(line=number, error=str(exc), possible_truncated_tail=tail))
    layers = layers if layers is not None else metadata.get('layers')
    experts = experts if experts is not None else metadata.get('experts')
    integer(layers, 1)
    integer(experts, 1)
    if any(metadata.get(k, v) != v for k, v in [('layers', layers), ('experts', experts)]):
        raise ValueError('flags conflict with trace metadata')
    valid = []
    for row in rows:
        if row['layer'] >= layers or any(e >= experts for e in row['experts']):
            # Bounds violations are fatal: never silently simulate the wrong model.
            raise ValueError(f'expert/layer ID outside declared dimensions: {row}')
        valid.append(row)
    if not valid:
        raise ValueError(f'no valid routing records; malformed_lines={len(errors)}, possible_truncated_tail={truncated}')
    valid.sort(key=lambda r: (r['seq'], r['tok'], r['layer']))
    phases = {}
    for r in valid:
        key = (r['seq'], r['tok'])
        if phases.setdefault(key, r['phase']) != r['phase']:
            raise ValueError('inconsistent phases within a token')
    coverage = Counter((r['seq'], r['tok']) for r in valid)
    incomplete = sum(n != layers for n in coverage.values())
    return valid, layers, experts, dict(incomplete_layer_tokens=incomplete,
                                       malformed_lines=len(errors), possible_truncated_tail=truncated,
                                       errors=errors, valid_records=len(valid))


def token_keys(rows):
    return list(dict.fromkeys((r['seq'], r['tok']) for r in rows))


def partition(rows, split):
    if split is None:
        return [], rows
    try:
        train, test = map(float, split.split(':'))
        if not all(math.isfinite(x) for x in (train, test)) or train < 0 or test <= 0:
            raise ValueError()
    except ValueError:
        raise ValueError('split must be nonnegative-train:positive-test weights') from None
    keys = token_keys(rows)
    cut = int(len(keys) * train / (train + test))
    training = set(keys[:cut])
    return ([r for r in rows if (r['seq'], r['tok']) in training],
            [r for r in rows if (r['seq'], r['tok']) not in training])


def fingerprint(row):
    return hashlib.sha256(json.dumps(row, sort_keys=True).encode()).hexdigest()


def make_profile(rows, layers, experts, weighting):
    totals = Counter(r['seq'] for r in rows for _ in r['experts'])
    counts = defaultdict(float)
    for r in rows:
        for e in r['experts']:
            counts[r['layer'], e] += 1 if weighting == 'raw' else 1 / totals[r['seq']]
    ranked = sorted(((l, e) for l in range(layers) for e in range(experts)),
                    key=lambda p: (-counts[p], p))
    return dict(schema_version=1, layers=layers, experts=experts, weighting=weighting,
                ranked=[list(p) for p in ranked], scores=[counts[p] for p in ranked],
                training_records=[fingerprint(r) for r in rows])


def replay(rows, layers, experts, capacity, policy='lru', per_layer=False, warmup=0,
           expert_bytes=0, layer_bytes=None, bw_gbs=1.0, compute_ms=0.0, profile=None):
    integer(capacity)
    integer(warmup)
    if policy not in ('lru', 'lfu', 'belady', 'static-profile') and not policy.startswith('lfu-decay:'):
        raise ValueError('unknown policy')
    half = float(policy.split(':', 1)[1]) if policy.startswith('lfu-decay:') else None
    if half is not None and (not math.isfinite(half) or half <= 0):
        raise ValueError('half-life must be finite and positive')
    if not math.isfinite(bw_gbs) or bw_gbs <= 0 or not math.isfinite(compute_ms) or compute_ms < 0:
        raise ValueError('bandwidth must be positive and compute time nonnegative')
    integer(expert_bytes)
    sizes = [expert_bytes] * layers if layer_bytes is None else layer_bytes
    if len(sizes) != layers:
        raise ValueError('per-layer bytes must have exactly L entries')
    for size in sizes:
        integer(size)
    keys = token_keys(rows)
    unscored = set(keys[:warmup])
    events = [(r, (r['layer'], e)) for r in rows for e in r['experts']]
    future = defaultdict(deque)
    for i, (_, pair) in enumerate(events):
        future[pair].append(i)
    caches = defaultdict(dict)
    selected = set()
    if policy == 'static-profile':
        if profile is None or (profile.get('layers'), profile.get('experts')) != (layers, experts):
            raise ValueError('profile dimensions mismatch or profile missing')
        used = Counter()
        seen_pairs = set()
        for item in profile['ranked']:
            if not isinstance(item, list) or len(item) != 2:
                raise ValueError('invalid profile pair')
            l, e = item
            integer(l); integer(e)
            if l >= layers or e >= experts or (l, e) in seen_pairs:
                raise ValueError('invalid/duplicate profile pair')
            seen_pairs.add((l, e))
            scope = l if per_layer else 0
            if used[scope] < capacity:
                selected.add((l, e)); used[scope] += 1
    stats = defaultdict(lambda: dict(hits=0, requests=0, bytes_moved=0, tokens=set()))
    for i, (r, pair) in enumerate(events):
        future[pair].popleft()
        cache = caches[r['layer'] if per_layer else 0]
        hit = pair in cache
        if (r['seq'], r['tok']) not in unscored:
            for name in ('overall', 'decode' if r['phase'] == 'decode' else 'prefill', f"layer:{r['layer']}"):
                s = stats[name]
                s['requests'] += 1; s['hits'] += hit
                s['bytes_moved'] += 0 if hit else sizes[r['layer']]
                s['tokens'].add((r['seq'], r['tok']))
        if hit:
            freq, last = cache[pair]
            if half is not None:
                freq *= 2 ** (-(i - last) / half)
            cache[pair] = (freq + 1, i)
        elif capacity and (policy != 'static-profile' or pair in selected):
            if len(cache) >= capacity:
                if policy == 'belady':
                    # Include incoming pair: bypass permits the oracle to dominate pinned policies.
                    victim = max([*cache, pair], key=lambda p: future[p][0] if future[p] else math.inf)
                    if victim == pair:
                        continue
                elif policy == 'lru':
                    victim = min(cache, key=lambda p: cache[p][1])
                else:
                    victim = min(cache, key=lambda p: (cache[p][0] * (2 ** (-(i-cache[p][1])/half) if half else 1), cache[p][1]))
                del cache[victim]
            cache[pair] = (1.0, i)
    def finish(s):
        n, h, t = s['requests'], s['hits'], len(s['tokens'])
        misses = n - h
        return dict(hits=h, requests=n, misses=misses, tokens=t, hit_rate=h/n if n else None,
                    misses_per_token=misses/t if t else None, bytes_moved=s['bytes_moved'],
                    bytes_moved_per_token=s['bytes_moved']/t if t else None)
    overall = finish(stats['overall'])
    decode = finish(stats['decode'])
    prediction = (compute_ms / 1000 + decode['bytes_moved_per_token'] / (bw_gbs * 1e9)
                  if decode['tokens'] else None)
    return dict(policy=policy, oracle_label='reads-the-future upper bound' if policy == 'belady' else None,
                capacity_experts=capacity, per_layer_capacity=per_layer, warmup_tokens=len(unscored),
                overall=overall, decode_only=decode,
                per_layer={str(l): finish(stats[f'layer:{l}']) for l in range(layers)},
                prediction=dict(decode_seconds_per_token=prediction, bw_bytes_s=bw_gbs*1e9,
                                compute_s=compute_ms/1000),
                semantics='sequential expert lookups in recorded rank order; cold demand admission; persistent across phases/requests')

    tokens = defaultdict(list)
    for row in rows:
        if row['phase'] == 'decode':
            tokens[row['seq'], row['tok']].append(row)
    groups, current = [], []
    for key in sorted(tokens):
        if current and (len(current) == width or key "'!= (current[-1][0], current[-1][1] + 1)):
            groups.append(current)
            current = []
        current.append(key)
    if current:
