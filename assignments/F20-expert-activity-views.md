## Build
- `views/activity.py`: parse sources → a normalized JSON document (`expert_activity/1`) with provenance (source file, run id, image id, effective config line, phase coverage, sampling/aggregation notes, overhead mode).
- `views/render.py`: self-contained static HTML (no external network; inline SVG/JS; works offline; light/dark) with: (A) layer×token expert activity map for decode (each cell = the layer's 8 selected experts summarised by readiness class colours; click/hover shows ids, predicted set, bytes, wait); (B) predicted-vs-selected panel (recall per layer, timely/late/unused speculative reads); (C) per-token decode timeline: demand wait vs rest-of-token (only what is measured; label inferred attribution as inferred); (D) a compact "what changed and why" panel built from factory evidence: component applied → source commit + files changed → reason (decision text excerpt + evidence ids) → effective config → image id → resulting observation (engagement + A/B result).
