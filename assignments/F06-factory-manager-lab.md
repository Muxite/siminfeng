## Build (new files under `jiuwenswarm/factory/`, `tests/factory/`; plus `jiuwenswarm/factory/contracts/`)
1. `contracts/qwen36-greedy-v1.json` — versioned scored contract: `{contract_id, version: 1, scope: "identical greedy continuation of a fixed prompt; not an accuracy benchmark", model: {path, size, sha256: null|..}, workload: {tool, argv, env}, reference: {image_tag, image_id, stdout_sha256: null, frozen_at: null, run_ref: null}, tolerance: "byte-identical stdout", engagement_checks: [...]}`. `contract.py`: `load`, `freeze(contract, reference_run)` writes the reference sha **once** — refreezing a frozen contract raises `ContractFrozen` (a change requires version+1 file). `evaluate(contract, run) -> {execution_outcome, correctness: pass|fail|not_evaluated, evidence_completeness: complete|partial, details}` (three separate fields; a failed measurement is `not_evaluated`, never `fail`).
2. `manager.py` — deterministic `Manager(store, spool_root)`:
   - `admit(task_id, image_ref: {tag, id}, build_attempt_id) -> admission`: `docker image inspect` (via `sg docker -c`), require Id == build receipt image id (else `BAD_DIGEST`), `Architecture=arm64` and label target profile `jetson-orin` (else `WRONG_TARGET`); record admission artifact labeled `delivery: same_host_local_image` (no network transfer claimed).
   - `submit_run(task_id, admission_id, contract_id, run_config: {env, argv_overrides?}, idem_key)` → `Jobs.submit(job_class='gpu', ...)` of `lab_runner.py`; returns lab job handle immediately.
   - `status/cancel/result` delegate to `Jobs`; `result` returns evaluation + evidence refs.
   - `ingest_upload(task_id, lab_run_id, bundle_dir)` — the **only** path for lab evidence into the store: verify task/lab_run identity and bundle manifest sha256s, persist artifacts + observation + evaluation, then write `ack.json` (`{upload_id, sha256 of manifest, ack_state: durable}`) into the spool — only after the store commit. Repeat upload with identical manifest → same ack (idempotent); same lab_run_id with different bytes → `UPLOAD_CONFLICT`. On persistence failure: no ack, bundle remains for retry.
3. `lab_runner.py` — the fixed runner, executed by jobq **outside** the tested container: `python -m jiuwenswarm.factory.lab_runner --task T --run R --admission A --contract C --config cfg.json --spool DIR`. Steps: preflight (image exists by Id; model file size matches contract) → invoke siminfeng `cc/om_run/om_run.sh` with `OM_THREADS=1`, `OM_MIN_AVAIL_MIB=600`, model dir from contract → collect stdout/stderr/watchdog/telemetry/threads summary/cmd → parse `expert_config: effective` (requested vs effective comparison), `expert_config: invalid` (→ outcome `config_rejected` with the exact message), OOM/watchdog (→ `measurement_failed`), `xfill-*` thread presence → write bundle + manifest into `spool/<run>/` → call `Manager.ingest_upload`; if ingest fails, retry with backoff (bounded) and leave the spool for `python -m jiuwenswarm.factory.manager retry-spool`. Lab never opens the store directly (only via `Manager.ingest_upload`). Always reap its owned container on exit.
   Distinct outcomes: `ok`, `config_rejected`, `measurement_failed`, `candidate_failed` (correctness fail), `wrong_target`, `bad_digest`, `cancelled`, `upload_pending`.
4. `api.py` dispatch: `lab.submit|status|cancel|result` (submit takes `{image: {tag,id}, build_attempt_id, contract_id, run_config, idem_key}` → admission + lab handle), `inspector.verify_effective_config` is F04's, not yours.
5. CLI helper `python -m jiuwenswarm.factory.manager freeze-reference --contract qwen36-greedy-v1 --image campaign/llamacpp:jetson-up1108-om11` that submits the reference run through the same runner and, when it succeeds, freezes the contract (operator action; prints the sha).
