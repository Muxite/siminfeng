# Lab Manager design (derived from campaign operations; living document)
Scope: deterministic coordination only (no reasoning agent). The other team owns the lab agent / sandbox provisioning; our reference adapter is a TEMPORARY Docker-container stand-in (`bin/lab`), never claimed to be their lab.

## Responsibility map
| Actor | Owns | Evidence |
|---|---|---|
| Builder (coding sandbox) | source edits, patches, build CC invocations | builds/results/*/build-record.json |
| Build CC | source+patch+bases -> runtime image + archive + record (incl. failures) | W4 attempt 1 failure record |
| Lab Manager (controller) | immutable job spec, attempts, admission, ownership token, state log, export, registration, reconcile | lab/jobs/*, LAB-FEASIBILITY.md |
| Lab agent (other team) | accept/reject/needs-info, choose+provision sandbox | NOT exercised |
| Test sandbox | runs ONE test container per request; disposable; no docker socket; RO model/data | job CR1-crash |
| Evidence store | outside sandbox: stdout/stderr streamed to files, state.jsonl, export w/ MANIFEST | lab/export/* |

## Demonstrated behaviors (op/job refs)
idempotent submit + conflicting-spec rejection (job-3d376c81fb); attempts/retry-as-new (job-9252e2d8bf att-2; job-3739814377 att-2); cancel requested != confirmed (job-93d03ebe43); runner death -> orphan container found by label+token and killed (job-e91db9b081); death during export -> resume, no rescoring (D006 fix, job-5bbc09b093); late conflicting / foreign-token result rejected (cases 4a/4b); duplicate delivery during active attempt rejected rc 8 and replacement blocked until owner gone/reconciled (job-3739814377); controlled sandbox kill -> interrupted_sandbox_terminated with coverage, never pass, controller responsive (job-3739814377 att-1).

## Open / not demonstrated
Admission/queueing (user removed lock D007: single-job-at-a-time is procedural; no capacity model), leases/heartbeats (deliberately not used: liveness = pid+start-time and labelled containers), runner timeouts, disk/capture budgets, retention/GC, remote receiver acknowledgement states (received/accepted/rejected/needs-information are specified in engine_handoff but not yet exchanged with a real lab agent), host-loss failure domain (protected domain = sandbox/process only; evidence on same host).

## Additions from the memory-objective phase (D012-D015)
Demonstrated (job/op refs): image admission by archive: wrong sha256 -> rc 10, wrong expected config id after load -> rc 12, correct -> admitted (op "image-load b0 archive", builds/results/b0-baseline-3); Build CC emitted a patched engine in 18 s via ccache cache mount (builds/results/rt1) vs 7-11 min clean (b0-baseline-2: 11-min build lost to a link error; recorded as failed attempt with stage + full log); per-test memory sampling (GPU peak via nvidia-smi, container cgroup memory.peak and io.stat) with own-file cold cache and container memory limits (job-6e6b2d39b8); test definitions as data (lab/tests/*.json) with per-test env, model file, docker mounts, memory limit.
New requirements found by failure:
- R-A **Interface contracts between CCs must be pinned, not described.** The handoff CC (T-E) was given a flat build-record schema; the Build CC (T-D) emitted a nested one; admission refused a genuinely good delivery (experiments/handoff-real/verdict.json). Needed: a versioned build-record schema owned by one place, plus a normalizer test across both. -> Manager/CC-registry concern, not agent reasoning.
- R-B **Observed vs declared must be enforced by the admission tool**: values from the build record are claims; image config id, platform and executable hashes must be re-observed from the archive (T-K).
- R-C **Concurrent work contaminates measurements** even without a GPU lock: build/compile jobs (load avg up to 18/16 threads) distorted CPU-expert speeds (D015). Admission must also cover CPU/IO load or record load average and mark runs contaminated. (GPU lock was removed by the user, D007; this is the observed cost.)
- R-D **Memory is a first-class measurement**: GPU peak + container peak + physical reads, with cold/warm declared per test; a result without a declared cache state is not comparable.
- R-E Delegated agents (Codex x11, Opus x1, Sonnet x1, gpt-6-astra advice x1) required written assignments, write-location scoping and independent re-verification: Codex G's and H's analysis was high quality; Codex-written code passed its own tests but the integration (R-A) failed only when two outputs met.

## Additions from c2-resume (D020-D024)
Classification key: MP = Manager policy | LP = lab-provider behaviour | CC = reusable CC operation | CMP = component | AM = agent methodology. Anything not listed as demonstrated is "not demonstrated".
1. **Raw bytes in, decode only at the parser; parser errors never kill the runner** (MP+LP). Event: job-8df3c7bb27 att-1 died with UnicodeDecodeError in assess(); reconcile marked it interrupted, nothing scored (D020). T-M: assess() reads bytes, flags `invalid_utf8=true`, converts any parser exception into `assessment_error` while exit code/elapsed/mem are still recorded; stdout/stderr files are never rewritten. Orchestrator policy: invalid UTF-8 in GENERATED text is flagged, not failed (att-2 st_prose_n18 flagged invalid_utf8 and still scored, D022); a flagged output is never silently clean. Demonstrated on att-2 (10/10) and 17 CPU-only tests; Docker/GPU runner path under T-M was mock-tested only by Codex.
2. **Per-test input identity** (LP). Event: job-8df3c7bb27 hashed the bf16 GGUF while every test loaded mixE4K, so the model actually used was unverified (D021 gap). T-Q: submit records `spec.inputs` (every model_file hash, referenced prompt/data file hashes from ro mounts, per-test definition hash); re-verified in the preparing phase, mismatch -> not_started; legacy specs keep their idempotency check and run with `inputs_unverified=true`. Limits: literal argument paths only, no indirect dependencies, no check after verification. 48 CPU-only tests; not run against a live job.
3. **A rerun is a new attempt, never a relabel** (MP). Event: D020 was completed as job-8df3c7bb27 att-2; att-1 stays `interrupted` with its partial output. Same rule as earlier retry-as-new (job-9252e2d8bf att-2).
4. **Memory-budget guarantee taxonomy** (MP). Classes: none | cooperative-intercept | cgroup-host | hard. The gpu_budget LD_PRELOAD shim is cooperative-intercept only: bypassable via VMM pool (cuMemCreate), static cudart, cuGetProcAddress, other processes (D021). With NO_VMM it counted weights 778.7 + KV 192 + compute 108 MiB (peak 1078.9) vs ~1388 MiB nvidia-smi delta, ~310 MiB uncounted (D023). Cap 900 + forced -ngl 99: KV denied, clean abort rc=1 (enforcement works on intercepted paths). Rules: report shim peak AND nvidia-smi delta, declare n_ctx, place experts explicitly (auto-fit under the virtual budget placed 155 MiB, D023). Hard device-memory limit: not demonstrated. cgroup-host class: container memory limits exist (job-6e6b2d39b8) but are not a GPU guarantee.
5. **Image identity: four different digests** (CC+MP). Docker reported ID (`image inspect .Id`), config digest, manifest digest, index digest. Under the containerd store `.Id` is the INDEX digest (D016). Buildx metadata there has only `containerimage.digest` (= index) and no `config.digest`, so T-N code failed novmm-1 at inspect_image (D023); T-N2 derives config digest from the saved archive and cross-checks metadata when present. Reference accepted by `docker run`: the docker-reported ID (index digest) works (shot-2 run_ref 7040afcd..., used for D024); the bare CONFIG digest was rejected, exit 125 (novmm-2 and shot-1, failure_stage hash_tools, config 0b78d876... / 8edec18d...). Rule: record the config digest for admission/observation, keep a separate `run_ref` for execution, never treat an index digest as a config ID. Receiving a repo@digest of a local-only image: rejected in a prior probe (per T-N2 assignment); run_ref field in shot-2/novmm-3 records is the evidence of the current approach, not yet shown for novmm-2/shot-1 reruns.
6. **Synthetic fixtures hid two real-world failures** (AM+MP). T-N passed 76 mocked tests yet failed on the first real build (novmm-1, metadata shape); then linkage failed on novmm-3 and shot-2 because the runtime image has no readelf/nm (ldd ran, libcudart dynamic=True); T-N3 moves symbol inspection host-side (delivered? not confirmed here, see inventory). Rule: every CC that parses another tool's output needs at least one saved real-record fixture (e.g. cc/build_engine/fixtures/buildx-metadata-containerd-real.json) before acceptance. Also: a build whose later stage fails is recorded status=failed, not a release (D023).
7. **Engagement check before a timing window** (AM). Event: T-O static hot-expert mode compiled, left the default path unchanged, and never engaged (D024: static 325/487 produced the CPU-path text sha 76dc9422 and speed ~off, 100-111 vs 102 t/s). Rule: first GPU test of any candidate observes engagement (counter, log, or greedy-output fingerprint at temp 0; CPU vs GPU experts give different text for this model). Speeds in D024 are untimed (host load ~6).
8. **Host-load monitor during timing windows** (LP+AM). Extends R-C. D022 ran with a monitor; the first monitor self-matched its own pattern (false "compiler active"), was verified and fixed (artifacts/x2/*hostload.log). Rule: a monitor must exclude its own process and be validated by a positive control; a window with a busy host is labelled untimed. Matched comparison: alternating order per round, medians of 3, identical output hash across configs (D022, one prompt, decode only).
9. **Resource observation contract** (CMP). T-P resource_observe: backends explicit, missing data is status unavailable never 0, device-total vs per-process scope, loss accounting. Tested on a real x86 fixture (captured by the orchestrator on the host against the live driver: cc/resource_observe/tests/fixtures/x86-main-real-sample.json; the Codex sandbox itself had no driver); Jetson/tegrastats backend not demonstrated. Note Codex P's own run found nvidia-smi unavailable in its sandbox; GPU parsing there used fixtures.
10. **Job envelopes** (CC, T-S): delivery and result unknown here; not demonstrated.
